# Probe: where each file's held name stands in the 2D card ladder

_Status: an instrument of 2026-11-07 and the style of one alternative, kept beside [the one-line names evidence](../../../Screenshots/2026-11-07/one-line-names/README.md), whose counts and pictures they made. They drive a private headless Chromium (Playwright's) against a served bundle and change nothing in the product._

Build and serve first (`npm run build`, `npm run live-docs:visualize`, `npx http-server dist/explorer -p <port> -c-1`), then run from the repository's root with `npx tsx AI-Agent-Workspace/Probes/2026-11-07/one-line-names/held-names.cjs`, under the machine's browser lock when other browser runs share it.

| File | What it is | Switches, in the environment |
| --- | --- | --- |
| `held-names.cjs` | Loads a subject in the 2D Local Map with a fresh visitor's settings and the background search off, presses Zoom Out until it is disabled, and at each press reads every card's held file name: the lines the attribute for the band and step shown holds, classified as whole beside the node's buttons, whole below them, cut with an ellipsis, or on two lines (bundles before 2026-11-07). Prints one line a press and writes the reading as JSON, with pictures at chosen presses | `SUBJECT` (a file path), `NAME`, `PIN` (`none`, `whole`, `search` for the address the search gives when the file is chosen, `symbol:<name>` for a row's Pin pressed at reading scale), `BASE` (the served bundle, port 8911 by default), `OUT`, `SHOTS` (a comma list of presses, or `all`), `CSS` (a stylesheet to inject), `RECHOOSE` (choose each name's line again in the page by the one-line rule, in the room the buttons as drawn leave), `PAN`, `FROM` and `PANAT` (a second picture with the map dragged, at chosen presses), `W`, `H` |
| `more-one-line.css` | The alternative pictured for the owner: the node's held More at the far and overview bands no taller than one line of the held name. Used with `RECHOOSE=1` | |

On 2026-11-08 the header round extended `held-names.cjs` in place, for [the header order evidence](../../../Screenshots/2026-11-08/header-order/README.md): each card's reading now also records its header's order (how many lines the name stands on, whether whole, whether its first line is empty, and whether the node's drawn controls stand on the name's last line, on the line after, or above a line of the name), and `ORDER=1` prints the counts that way: whole on one line sharing it with the controls, whole on one line with them alone after, whole on two lines or more, and cut, with where the controls stand.
