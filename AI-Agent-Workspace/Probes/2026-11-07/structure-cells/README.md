# The instruments of the bag of cells in Structure, November 7

_Status: the instruments a builder used on 2026-11-07 and 8 to measure the 3D Local Map's Structure layout drawn as a bag of cells, kept so that the measurements can be run again. The numbers and pictures they produced are in [the structure-cells pictures](../../../Screenshots/2026-11-07/structure-cells/README.md)._

Each script runs from the repository root with `npx tsx`. The browser scripts drive a private headless Chromium (Playwright's) against a served bundle on `PORT` (8912 by default): build it (`npm run build`, `npm run live-docs:visualize`, the estate sample's `live-docs:visualize:estate`) and serve it (`npx http-server dist/explorer -p 8912 -c-1 --silent`). Group Wrappers and the hops are set as saved Tuning choices, the background search off. To compare two commits' pictures, serve the older commit's bundle on the same port, take the same pictures, and compare the files byte for byte (`cmp`).

| Script | What it measures | Switches, in the environment |
| --- | --- | --- |
| `rest.cjs` | The Structure picture with nothing pinned, in each look in turn: the frames drawn and the page's seconds until it rests, what it holds at rest (spheres, hubs, bubbles and the files they hold, skins, the files and bubbles drawn within them, veiled ones), the packing's parts over frames and its longest part, the longest tasks the browser saw, and its picture at 1440 × 960 | `PORT`, `BASE`, `OPEN` (directories opened), `LOOKS`, `HOPS`, `OUT`, `NAME`, `TIMEOUT` (seconds to wait for rest) |
| `twin.cjs` | Headless, milestone 2 (November 8): the Structure start eased by `easeSpatialLayout` until still, Off and with the bubbles, each sphere born where its hub's packing holds it and each spoke as long as `structureSpokes` packs it with the collision's or the link's gap; the ticks to rest of each. It bears every sphere at once, so it does not reproduce the page's reveal | `BASE`, `HOPS`, `GAPS` (`none` for milestone 1's spokes), `GRAVITY` |
| `entry.cjs` | What moves while the Structure start enters and settles: every drawn frame's places from the page's node buffer, the frame the last sphere entered, the frame of rest, the motion in windows of frames and the spheres that travelled farthest during and after the entry | `PORT`, `BASE`, `LOOK`, `HOPS`, `WINDOW`, `TOP`, `TIMEOUT` |
| `pop.cjs` | Bubbles opened in a row by a click on each one's name, after the third round's `look.cjs`: each pop as three pictures (before, panned to the middle of the frame by right-drags; the frame of the pop, the page's clock paused and stepped one frame; at rest), how far what it released stands from where its skin showed it, whether inside the skin and at its bubble's size, the opened set the address carries, the drawing budget at rest, and the frames to rest after the pop | `PORT`, `BASE`, `HOPS`, `LOOK`, `POPS`, `OUT`, `NAME` |
| `pack.cjs` | Headless, by the third round's `pack.cjs` method: each bubble of the Structure start (or with `OPEN`) packed with `bodyShape`, the least of `REPEAT` runs in processor time, the hubs of one file (`lone`), and the whole repository packed from the leaves as the root's one bubble | `BASE` (a folder with `explorer-data.json`), `HOPS`, `OPEN`, `REPEAT` |
| `onecell.cjs` | Whether any bubble of a picture shows a single cell (the owner's "Make no embryos which appear to have only one cell"): what each skin and each inner bubble shows within it, a wrapped group's seed counted, veiled bubbles apart | `PORT`, `BASE`, `LAYOUT`, `PIN`, `HOPS`, `DEPTH`, `OUT`, `NAME` |
| `history.cjs` | One playback of the bundle's history in the Structure layout: History opened (with nothing asked about, the scan root opened), Play pressed, and each step read as it is shown: how long it stood, the frames drawn, whether its picture was built before the next step (the timeline's `live-docs:shells` measure, made once every body a render names is packed), the packing meanwhile, and the longest tasks | `PORT`, `BASE`, `LOOK`, `HOPS`, `LIMIT` (seconds), `ROWS` (each step's row), `OUT` |
