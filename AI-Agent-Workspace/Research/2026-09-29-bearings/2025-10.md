## The story of the slice

October 2025 is the project before it had its name, its picture or its human audience. On 2025-10-16, in a repository called Copilot-Improvement-Experiments on a Windows machine, the owner asked Copilot how to build a VS Code extension or language server that would raise a "problem" in one file when a file linked to it changed, docs to code and code to code, so that "Github Copilot, while working in agent mode, [would] be given intuitive clues about salient context sitting _just outside_ the bounds of its current windowed knowledge, _based on the changes it is making_" ([2025-10-16.md](../../ChatHistory/2025/10/2025-10-16.md), line 5). The same prompt described the four layers of markdown they already kept. SpecKit wrote a constitution and a spec, `001-link-aware-diagnostics`, and the first fortnight built the diagnostics: a language server over SQLite, ripples with a depth, hysteresis so that A warning about B did not make B warn back, an acknowledgement ledger, and knowledge feeds read from SCIP and LSIF compiler indexes. By 2025-10-19 the owner had written, by hand, the "Behavior Expectations" that became AGENTS.md eleven months later, and named the layers Membrane Design MarkDown.

The owner was product manager, architect and the only pair of eyes. Copilot's terminal tool reported green before the tests had finished, and the owner pasted the real output, day after day: "An unfortunate lie that VS Code is telling you" ([2025-10-23.md](../../ChatHistory/2025/10/2025-10-23.md), line 4056). Every morning began with the agent summarizing the day before and every afternoon with it losing the thread to "autosummarization"; the owner coached it through both ("strike your proverbial mental pitons into the metaphorical rock wall of this problem", [2025-10-25.md](../../ChatHistory/2025/10/2025-10-25.md), line 8).

The month turned on 2025-10-24. Tools that audited this repository's own docs led the owner to ask why the tooling knew about MDMD at all ("That's a very niche docs-to-code specification format. The tooling we want to build is far more generic", [2025-10-24.md](../../ChatHistory/2025/10/2025-10-24.md), line 1742) and then to call a model "a crucial ingredient": "We do _not_ need a million and one different file type-specific parsers and pattern matchers. We need a good set of prompts and an LLM" (line 1780). From there the work ran in two directions at once. One was models: relationship extraction, confidence gating, a local Ollama bridge on the owner's RTX 3090. The other, which is what survived, was markdown as a checkable structure: SlopCop on 10-25 (broken links as "a telltale sign of LLM hallucinations", a ladder from links to asset paths to symbols); on 10-26 every public symbol required in a layer-4 doc, and the owner's "What if we could run this process in reverse?", docstrings and layer-4 docs generated from each other; on 10-27 and 10-28 the chat record mined for intent into censuses, and a benchmark against "real AST" begun, with self-authored fixtures accepted as "a fair substitute".

On 2025-10-29 the owner reached "the upper limit of our initial vision" and argued with themselves in the open: "Live docs is great, but is that core to the mission?" and "the workspace is the entire universe" ([2025-10-29.md](../../ChatHistory/2025/10/2025-10-29.md), lines 4804 and 4806). The next morning they said, in one sentence, what the product would become: "the major draw... is this mandate that every code file receive its own layer 4 MDMD doc and every layer 4 MDMD doc expose its public symbols" ([2025-10-30.md](../../ChatHistory/2025/10/2025-10-30.md), line 250). The month closed on 10-31 scoping the benchmark against compilers ("Roslyn is absolutely top-of-class") and weighing whether to test on someone else's code at the risk of "the pie in the face".

It felt like an adventure. The owner was delighted by long agentic streaks ("Absolutely electrifying to watch"), by hearing the computer's fan spin up when a local model ran, by "symbol-level intelligence, docs-to-docs and code-to-docs, in a day". They were patient with the tools and funny about them ("I think I may facepalm myself into the floor"). The audience was Copilot, said plainly and often; success was "a lattice of truth that is verifiable and auditable and capable of being entered and queried from anywhere in numerous different ways" ([2025-10-27.md](../../ChatHistory/2025/10/2025-10-27.md), line 6063). Nobody in October asked to see the graph.

## Surprises

1. **The audience was reversed at the root, not after a drift.** Copilot was the audience from line 5 of the first prompt, and the owner said it plainly all month: "It is only us developing this; we're trying to make it so Github Copilot can, through excellent specification, create a true enhancement on its own functionality" ([2025-10-25.md](../../ChatHistory/2025/10/2025-10-25.md), line 4202); "The primary consumer of the outputs of our tooling are LLMs!" ([2025-10-29.md](../../ChatHistory/2025/10/2025-10-29.md), line 4858); "The structure of MDMD is very much built to help _you_, Github Copilot" ([2025-10-30.md](../../ChatHistory/2025/10/2025-10-30.md), line 412). September's "Humans are the audience" turns the founding around. And in October nobody asked to see the graph: offered "drift dashboards" and "tree views", the owner answered "Yes **BUT**" and asked for ASCII diagrams an LLM could read.
2. **The owner was the most pro-model voice in the room.** Offered a local-only default by the agent, they chose instead to force a provider choice on first run and block diagnostics until one was made; their first answer, struck through only because they had misread the option letters, gives the reason: "That is preferable to attempting to engineer this with no LLM at all." ([2025-10-16.md](../../ChatHistory/2025/10/2025-10-16.md), line 715). They made model inference the default and a compiler's AST "a little sugar on top" (line 1269), and on 2025-10-24 said "We need a good set of prompts and an LLM" in place of "a million and one different file type-specific parsers" ([2025-10-24.md](../../ChatHistory/2025/10/2025-10-24.md), line 1780).
