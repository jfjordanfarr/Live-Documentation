**The reorder.** The owner: "it would be **really** time-saving to have `npm run live-docs:generate` happen **before** the rest of the `safe:commit` pipeline. The number of `graph:audit` fails we've run into just because the docs weren't generated is embarrassing. [...] when I watch the `safe:commit` logs as they're coming out, I see a rapid-fire entry for the generation of the live docs but none of the terminal output after that I would expect.
