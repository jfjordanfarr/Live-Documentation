## The five carries 0de42d28 claims

All five are in the decisions log, in the two entries `0de42d28` added (log, lines 199 and 200). None came from a retired layer-3 doc's text: the layer-3 docs name partial types and WebForms overrides in a line each, and say nothing of headers. They came from the code, the fixture files, the layer-4 docs and the transcripts, which is where the knowledge was.

1. **C# partial-class peers** (log, line 199): "linking every C# partial-class peer flooded a Roslyn slice with false positives in November 2025, and only generated peers (`*.designer.cs`, `*.g.cs`) were linked after that". Faithful: the retired heuristic linked peers only when the source file ended in `.designer.cs` or `.g.cs` (`ae216cb5:packages/shared/src/inference/heuristics/csharp.ts`, lines 333 to 336), a rule tightened "while integrating the Roslyn benchmarks and eliminating partial-class false positives on Nov 8" (the layer-4 doc of that file at `ae216cb5`, line 12). One detail is lost: the link ran from the generated file to the hand-written one, the reverse of the compiler's direction, which is what made carry 3 necessary. **Now stale**: the same entry says "the shipped C# adapter has no partial-peer handling at all ... so the tree-sitter adapter must cover it", in the present tense, and the tree-sitter adapter that landed later that day does cover it, linking a partial class to the peer that declares the members it uses (log, line 51; [csharp.ts](../../../../packages/engine/src/live-docs/adapters/csharp.ts), line 11; test at [csharp.test.ts](../../../../packages/engine/src/live-docs/adapters/csharp.test.ts), line 174). A reader of line 199 alone would think the gap is open.
2. **C headers as nodes** (log, line 199): "A C oracle that scanned only `.c` files silently dropped every header-to-header include; headers are nodes." Faithful and complete as a lesson. What it leaves out is whose it was: on 2025-11-05 the agent reported that libuv's expected edges had fallen from 22 to 2 because "Headers are no longer scanned" ([2025-11-05.md](../../../ChatHistory/2025/11/2025-11-05.md), lines 3531 and 3532), and the owner answered "WHAAAAA?? Faithful in substance, but the quotation marks are the log's own: the file's words were "SCIP direction differs from heuristic; partial classes link designer→cs not cs→designer" (`0de42d28^:tests/integration/benchmarks/fixtures/csharp/webforms/oracle.overrides.json`, line 33).
