6. **Links** are relative to `readers/`: a transcript is `[2025-12-17.2.md](../../../ChatHistory/2025/12/2025-12-17.2.md), line 123`, and a file in the repository is `../../../../packages/...`. Before you finish, run `npm run -s slopcop:markdown` from the repository root and fix any broken link in your file.
7. **Change nothing but your file.** No other edits, no `git` command that writes, no `npm` script that builds, generates or tests; `npm run live-docs:inspect`, `npm run live-docs:lint` and the markdown audit are allowed. Never open Claude Code's session logs, anything under `~/.claude/projects/` or any `.jsonl` file.
8. **The first brief's other rules hold:** old certainty is history, never a current decision; plain words; no emoji; no invented estimates; the owner's words weigh above the agent's.
