# The work items themselves

**For the owner.** You asked for "some kind of way to track work-item-like things", local, a little more formal than Markdown, and formal only where it streamlines. [This folder](README.md) is root's proposal, shown as the road to the December showing so that you can judge it on real content before any tooling is built for it.

**Done when.** You have said the form serves, or changed it; a small script checks the fields and prints the board; and the three places that list work today point here and stop repeating it.

**Waiting on the owner.** Does the form serve: one file an issue, named in plain words, its tasks inside it, evidence written on the task? What would you change, from what you use at work?
