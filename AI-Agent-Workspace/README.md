# AI-Agent-Workspace

The record of building this repository with AI coding agents, and the memory those agents share.

- `Memory/` is **current**: what the owner has said about how to work here and where the project is going, kept as plain markdown so that an agent of any vendor reads the same facts. [owner.md](Memory/owner.md), [direction.md](Memory/direction.md), [ideas.md](Memory/ideas.md), and [narrative.md](Memory/narrative.md), the story of the workspace from its first prompt, kept current as history. Read them after [AGENTS.md](../AGENTS.md).
- `AgentSessionHistory/` is the development system of record, one directory per dev day: source captures, reconstructed transcripts and records of each session, with summaries at month level that point back to their evidence and verified commits. Each day's directory also holds what that day made: `Probes/`, dated records of design probes (the brief, each builder's findings and a few screenshots; a probe page is disposable and not committed, unless it is one the owner is asked to open on a machine of their own, which is committed beside its record, and the layout lab's page captures are rebuilt on demand and not committed); `Research/`, surveys of formats and prior art gathered for a design step, with a source for every claim, recording what existed on its date and deciding nothing; and `Screenshots/`, pictures of the built Explorer taken by the agent after changing it, each named in its folder's README and listed in the month's inventory. [Its README](AgentSessionHistory/README.md) defines the layout ([where things are](AgentSessionHistory/README.md#where-things-are)), the shared convention across harnesses and the session handoff routine. Until 2026-11-18 the history was `ChatHistory/`, beside `Probes/`, `Research/` and `Screenshots/`; [old-paths.md](AgentSessionHistory/old-paths.md) maps the old paths to the new.
- `Gallery/` holds one representative picture per subject, view and state, copied with its origin named, and side-by-side sheets that `sheets.sh` rebuilds, so that a comparison across views starts from one folder; [its README](Gallery/README.md) is the comparison set.
- `Notes/` holds planning documents, censuses of user intent and use cases, and design notes from the Copilot era. Their quotations are not all verbatim; the intent census carries a dated list of corrections.
- `scripts/` holds helper scripts from the same period, and `claude-code-transcript.mjs`, which rebuilds the Claude Code transcripts. Since 2026-11-16 it also holds `visible-messages.mjs`, which lists what a Claude Code root session showed as messages, the owner's and the root's alone; [the recording convention](AgentSessionHistory/README.md#recording-as-work-proceeds) says when to run it.
- `tmp/` is scratch space, not tracked.

Everything from the Copilot era is **historical**. It describes nothing about the current state of the code, and links inside it may point at documents that no longer exist; that is expected, and they are not maintained. Current status and intent live in [the vision](../.mdmd/layer-1/vision.mdmd.md), with priorities and decisions in [direction.md](Memory/direction.md). [AGENTS.md](../AGENTS.md) is the working guide. The archive preserves provenance after an investigation or summary is complete; when intent signals conflict, the newer one wins.

Raw transcripts and records are excluded from the Explorer bundle by `bundleExclude` in `.live-docs.config.json`; linked summaries and the days' probe, research and screenshot documents are included. The archive's captures, records, summaries and READMEs, `Notes/` and `scripts/` are excluded from the default SlopCop audits, while each day's `Probes/`, `Research/` and `Screenshots/` are audited; check newly authored archive indexes and summaries explicitly. `Memory/` and this file are audited.

## Local product outputs

This repository's [.live-docs.config.json](../.live-docs.config.json) places the generated mirror in `.mdmd/layer-4/`, one document per tracked source file. The authored layer-1 through layer-3 documents identify themselves as current or historical. Shipped product defaults are `.live-documentation/source/*.md`; product code reads configuration rather than assuming this workspace's layout.

The graph index is derived afresh from the docs at `<root>/index.json` (`.mdmd/index.json` here), ignored and never committed. History generation writes its cache and sequence under `<root>/history/`; the directory ignores itself in any repository. The static Explorer is built under `dist/explorer/`. These outputs are distinct from the preserved source captures and authored evidence above.
