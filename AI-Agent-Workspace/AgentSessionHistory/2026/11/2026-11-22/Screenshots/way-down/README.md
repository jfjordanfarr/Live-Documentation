**What the route is not.** It is one shortest connection between the two files. It goes by `Payment.cs` and `GatewaySettings.cs`; a payment in fact passes through the stored procedure, the data context, the gateway's hub proxy and the hub's own code ([the sixteen steps written from the source](../../../2026-11-21/Probes/blind-playtests/README.md#the-answer-written-before-any-run)), none of which is on it. The report says "Path found: 12 files", which is true, and a person who came for "what happens to a payment" would read more into it than it says.
