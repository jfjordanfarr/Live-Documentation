GitHub Copilot: **Spatial Layout Strategy**
- Treat every directory node as a bounded 2D canvas; compute its width/height from the aggregate footprint of its children rather than letting CSS auto-flow. That means recursing from leaves upward: size files first, then bubble their dimensions back through parent directories so each parent can tile children on a near-square grid (target aspect 4:3) using a deterministic packer (spiral or best-fit decreasing square packing works well for grids).

Place the most connected child at the centroid, then fill remaining slots by greedily choosing the candidate that minimises additional edge length when positioned in neighbouring cells.
