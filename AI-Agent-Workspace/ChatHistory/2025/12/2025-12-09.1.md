## The Live-Documentation Project Trajectory

### What Have We Been Trying to Build?

**The Mission (unchanged since October 16):**
> "For any given change in any given file, this extension provides the definitive answer to the question: 'What other files will be impacted by this change?'"

We're building **Live Documentation** — a VS Code extension and CLI suite that:
1. Mirrors every tracked workspace artifact into deterministic markdown under `/.live-documentation/`
2. Generates structured `Public Symbols`, `Dependencies`, and `Observed Evidence` sections per file
3. Enables change impact analysis for humans and copilots alike through a markdown-as-AST graph
4. Provides visual exploration via Circuit Board (treemap), Local Map (3-column dependency view), and Force Graph views

---

### How Has Our Vision Changed?

#### **October: "Link-Aware Diagnostics"** (Foundation)
The project began as an LSP extension with SQLite graph backing. The focus was:
- Benchmark discipline with fixture oracles for polyglot parsing
- SlopCop tooling for markdown/symbol audits
- SpecKit-driven development workflow
- Ripple detection across a 4-layer MDMD documentation structure

#### **November: "Live Documentation Pivot"**
Mid-November saw a major architectural shift:
- **Live Docs replace the graph store** as the source of truth — deterministic markdown mirrors with `## Authored` and `## Generated` sections
- **Language adapters** added for TypeScript, Python, Ruby, Rust, C, C#, Java, and PowerShell (with structured docstring bridging)
- **System Layer** introduced for ephemeral materialized views with statistical clustering
- **`live-docs:inspect` CLI** (the "Oracle of Bacon") for path-finding through the dependency graph

#### **December: "Visualization Epoch"**
The most recent phase focused on making the graph *explorable*:
- **Circuit Board view** — treemap-style layout of directories and files
- **Local Map view** — 3-column symbol-level dependency visualization
- **Type reference extraction and resolution** — linking types to their defining files
- **French Corset self-loops** — intra-file dependency visualization
- **Hover highlighting** — subtractive dimming for relationship tracing
- **Static Explorer** — deployable JSON bundle for GitHub Pages/Teams embedding
- **Headless Local Map API** — `/local-map?nodeId=<path>` for programmatic inspection
