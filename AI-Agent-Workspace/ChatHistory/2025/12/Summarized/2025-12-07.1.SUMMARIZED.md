## Key Insights & Design Decisions

1. **Static Explorer is a Distribution Format** — The server remains for local development; JSON enables external consumption (GitHub Pages, Teams Cards, offline bundles).

2. **Headless JSON Eliminates Image Analysis Errors** — Instead of parsing screenshots, Copilot can query `/local-map` for structured data about any node's neighborhood.

3. **Bundle Full Markdown, Not Just Snippets** — The Hosted Showcase use case requires complete documentation, not just graph metadata.

4. **Hybrid Detail Panel Rendering** — Metadata and Generated Content use terse badge-style rendering; Authored Content uses full markdown.

5. **Link Navigation Rules** — Internal Live Doc links navigate within explorer; external links open new tabs; workspace file links use repo URL prefix (static) or VS Code (server).

6. **"Two Birds, One Stone"** — Static export and headless JSON API share the same architectural transformation (server-computed data → portable JSON).
