## Design Insights

### Module Extraction Success
The extraction of `state.ts`, `connection-geometry.ts`, and `layout-math.ts` as pure functions was successful — 153 new unit tests prove the logic works independently of DOM. This validates the "independently improvable modules" approach.

### Path Mode vs Exploration Mode
The key insight is that path mode and exploration mode should share rendering infrastructure but differ in:
- **Data source**: Path mode uses filtered edges between adjacent path nodes; exploration mode uses full subgraph
- **Column structure**: Path mode = linear chain (no dependencies column); exploration mode = 3 columns
- **Anchor registry**: Path mode needs hop-aware keys for duplicate nodes

### Bidirectional BFS Is Wrong For Dependency Visualization
The original BFS treated the graph as undirected, finding paths like `A ← B → C ← D` which don't represent actual dependency chains. The fix to try outbound-first, then inbound-only, ensures paths respect dependency direction.

### Screenshots Degrade VS Code Performance
Both sessions were cut short due to accumulated screenshots causing VS Code to become unresponsive. The user noted: "the more screenshots that go into a chat history, the slower VSCode performs, until it finally just stops."

## Design Insights from Chats 3-5

### Barrel File Resolution Is Non-Trivial
The barrel file problem has recurred across 6+ dev days. The resolution required:
1. **Chat Archaeology** — understanding the full timeline of the problem
2. **Consolidation** — finding and unifying 3 scattered `isBarrelFile` implementations
3. **Root cause identification** — tracing from the visual bug (false path) to the symptom (false edge) to the cause (symbol resolution in rendering.ts)
4. **Proper abstraction** — creating `compareSymbolLocationsPreferOrigin()` as a reusable comparator

### Playwright Screenshot Overload
Chats 3 and 4 crashed due to 413 Request Entity Too Large errors from screenshot accumulation. The user noted:
> "If you take too many screenshots in a single response via Playwright, the copilot chat becomes fully unusable"

**Mitigation**: Limit to 1-2 screenshots per response.

### Direction Detection for Path Visualization
The path visualization needed to indicate whether the path follows dependency direction (FROM depends on TO) or reverse direction (TO depends on FROM). This distinction is critical for user comprehension.
