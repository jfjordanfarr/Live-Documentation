## Design Insights

### npm Optional Dependency Handling
The Rollup CI failure exposed a known npm bug (https://github.com/npm/cli/issues/4828): package-lock.json generated on Windows omits Linux optional dependencies. Two potential fixes:
1. **`npm install` instead of `npm ci`** — More tolerant but less reproducible
2. **Explicit post-install** — `npm ci` + explicit install of platform-specific packages

The second approach is more durable because:
- Works regardless of which platform generated the lockfile
- Doesn't depend on cache state
- Is explicit about the workaround (documented in CI config)

### Chat Archaeology for README Alignment
When README updates diverge from prior decisions, Chat Archaeology provides the definitive source of truth. Key findings from this session:
- GitHub Pages link was explicitly requested but missing
- Competitive landscape table was intentionally created but deleted
- Oracle of Bacon and non-headless Explorer inspect are the same feature
- docs→code bridging is explicitly deferred to wishlist

### Flaky Test Patterns
Integration tests involving diagnostic waits are inherently timing-sensitive. CI environments are slower than local machines. The pattern:
1. Test fails on CI with timeout
2. No code changes between working and failing commits
3. Solution: Increase timeout (but stay within overall test timeout)
