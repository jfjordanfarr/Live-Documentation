## Turn 13: Root Cause Discovery — Upstream Anchor Bug
- **Copilot**: Deep-dived into `render.ts` anchor registration:
    - **Assets** get both `inbound:*` and `outbound:*` hubs
    - **Center column non-assets** get only `outbound:*` hub
    - **Upstream/downstream non-assets** get **NO file-level hubs**

**Root Cause**: Upstream nodes (dependencies) never registered `outbound:*` anchor, causing fallback to card center.

**Fix** (lines 395-401 in render.ts):
```typescript
// Upstream nodes need an outbound hub so file-level deps can anchor to their output pin
if (context.position === 'upstream') {
    context.registerAnchor(nodeId, 'outbound:*', outboundHubRef);
}
```
