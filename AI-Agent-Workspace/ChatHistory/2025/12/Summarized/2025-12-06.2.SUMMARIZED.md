## Turns 23–30: C Language Symbol-Level Dependencies
- **User**: Observed C files classified as "assets" and lacking symbol-to-symbol connections.
- **Root Cause 1 (Archetype)**: `resolveArchetype()` checked fixture patterns BEFORE test patterns.
    - **Fix**: Reordered logic to check `.(test|spec).[ext]` first.
- **Root Cause 2 (Symbols)**: C adapter populated `DependencyEntry.symbols` as `[]`.
- **Copilot**: Enhanced C adapter with holistic symbol detection:
    ```typescript
    async function extractSymbolsFromHeader(headerPath, workspaceRoot): Promise<string[]>
    async function detectUsedSymbols(sourceContent, headerSymbols): Promise<string[]>
    ```
- **Result**: C files now have `### Dependencies` with symbol-level links:
    ```markdown
    - [`logger.log_message`](./logger.h.mdmd.md#symbol-log_message)
    - [`metrics.compute_average`](./metrics.h.mdmd.md#symbol-compute_average)
    ```

## Turns 31–42: C# Inheritance Visualization
- **User**: Requested removal of default outbound hub for implementation/test nodes.
- **Copilot**: Modified `render.ts` to only show outbound hub for "asset" archetype.

### C# typeReferences Extraction
- **Gap Identified**: C# adapter didn't extract `typeReferences` (extends/implements).
- **Copilot**: Added `TYPE_WITH_INHERITANCE_PATTERN` regex and `extractTypeReferencesFromInheritance()`:
    ```typescript
    // Captures: class CompositeWidget : BaseWidget, IWidget
    const TYPE_WITH_INHERITANCE_PATTERN = /(?:class|struct|interface|record)\s+(\w+)\s*(?:<[^>]+>)?\s*:\s*([^{]+)/g;
    ```
- **Result**: C# symbols now show `- Extends: [BaseWidget](../BaseWidget.cs.mdmd.md#symbol-basewidget-class)`.

### Polyglot Symbol Index Extension
- **Gap Identified**: `buildWorkspaceSymbolIndex()` only processed JS/TS files.
- **Copilot**: Extended to use `analyzeWithLanguageAdapters()` for non-JS/TS files.
- **Result**: Symbol index grew from 946 → 1082 unique symbol names.

### Graph Building Fixes
- **Gap Identified**: Type references were in markdown but not in the graph.
- **Copilot**: Updated `liveDocGraph.ts` to add type references to `rawDependencies`.
- **Added**: `sourceAnchor` field to `ParsedDependency` for symbol-level connection endpoints.

### Symbol Anchor Normalization Fix
- **Issue**: `symbol-basewidget-class` (slug) didn't match `BaseWidget (class)` (name).
