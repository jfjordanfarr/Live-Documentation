## Design Insights

### Bidirectional BFS for Dependency Graphs
The Live Docs graph stores links as "source depends on target" (consumer → dependency). To find a path from A to B regardless of which is the consumer, the BFS must treat the graph as **undirected** by adding edges in both directions during adjacency list construction.

### Anchor Format Normalization
Live Docs use kebab-case slugs with `symbol-` prefix in anchors (`#symbol-graphstore`), but users naturally type PascalCase (`#GraphStore`). The solution involves:
1. `normalizeAnchor()` — strips `symbol-` prefix and lowercases
2. `symbolMatchesAnchor()` — compares normalized forms
3. `resolveAnchorToSymbolName()` — looks up actual symbol name in publicSymbols for output

### Multi-Hop Column Layout Challenge
The original 3-column CSS grid (`repeat(3, max-content)`) caused hop columns to wrap to the next row. Changing to `repeat(auto-fill, max-content)` allows dynamic column count but doesn't fully solve layout — further debugging revealed duplication and positioning issues that remained unresolved when the session ended abruptly.
