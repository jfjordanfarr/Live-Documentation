## Design Insights

### Symbol Collapse as Emergent Clarity
The user's insight that **symbol-level collapse** is simpler than **node-level hiding** proved correct. By collapsing irrelevant symbols within cards rather than hiding entire nodes:
- Cards shrink gracefully (no layout reflow)
- File-level context is preserved
- Recovery is automatic (unpin restores)
- Connection anchors naturally disappear (no explicit filtering needed)

### Attribute Selector vs. Loop Matching
The initial O(n×m) loop approach for connection path matching was fragile due to subtle data format mismatches between edges and paths. Direct CSS attribute selectors proved more robust:
- `[data-source-id="..."][data-target-id="..."][data-source-symbol="..."][data-target-symbol="..."]`
- Single query per related edge
- No normalization ambiguity
- Browser handles matching efficiently

### Terminal Management in Agent Context
The session revealed a recurring pattern where terminal commands inadvertently stopped the visualization server or failed to refresh. The user's solution — running the server from their own non-Copilot terminal — established a clean separation of concerns for long-running development servers.
