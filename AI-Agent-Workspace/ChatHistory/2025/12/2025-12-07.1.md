| Concern | Current State | Static-First State |
|---------|---------------|-------------------|
| Data generation | Node server live-computes | `npm run live-docs:export` emits JSON |
| Rendering | Server-rendered HTML + client JS | Pure client-side from static JSON |
| Hosting | Requires `live-docs:visualize` running | Any static host (Pages, S3, Teams) |

- The Explorer is a **read-optimized surface** for understanding
- Edits should flow through auditable channels (CLI, extension commands, PRs)
- Prevents accidental mutations from a "view-only" mental model

- **Teams Adaptive Cards**: Embed a mini Local Map for a file in a PR notification
