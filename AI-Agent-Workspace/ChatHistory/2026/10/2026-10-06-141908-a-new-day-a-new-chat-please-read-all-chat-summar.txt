  is already measured as the foreign-directory samples, which the membranes just
  halved. Your other one, a wire between two members of one membrane escaping
  it in the gutter, is not measured yet but is cheap to add, and it is
  expressible as constraints on the corridor, hard or weighted. The
  crossing-aversion lever cannot be graded in the exact placement, only
  forbidden or allowed, so it would live in the order step as a threshold.

  Wires reading backward. Already minimized, heuristically, by the cycle

  each cycle at its lightest reference by count.

  What was randomized

  The sweep drew random configurations of the levers: which gap, which pull,

  and placement are exact, so running them twice gives the same answer. The
  order step is a local search, and where it lands depends on where it begins. A
  "restart" means running that one step several times from different starts and
  keeping the best, every time the page lays out. That is the only lever where
  repetition buys anything.

  What I think is wisest

  Restarts in the page, deterministic, scored by a weighted sum of what the page
  can measure cheaply, with the weights in tuning.

  The reasoning:

  - Determinism. A fixed list of seeds, so the same pins give the same picture
    every time. Nothing random at run time.
  - The cheap signals are the right ones. The exact placement's measure is the
    vertical wire length, and it comes free with the solve. The order step
    already counts its own crossings. The picture's height falls out of the
    placement. Those three score a start in no extra time. The membrane signals
    need routed wires and sampling, which costs more than the layout itself, so
    they stay in the lab.
  - The lab tunes the page. A new lab report tabulates every start of a scope:
    the cheap signals the page would see and the full signals the deck would
    read. You set the weights so the page's choice agrees with the full picture.
    That is your "tabulated and tuned".
  - Cost. On the five-file scope the order step plus placement takes about 130
    ms. Eight starts add a second before the picture appears, four add half a
    second. The count is a dial.
  - The risk is continuity. Restarts can send the picture into a different basin
    when one pin changes. I would include the current order as a candidate
    start and a churn weight, so the page stays put unless another start is
    clearly better. The animated re-layout will depend on this.
