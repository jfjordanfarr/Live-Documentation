  The shape in plain words. A new command, live-docs:history, walks the
  repository's mainline commit by commit, checks each one out into a scratch
  worktree, runs today's generator over it with today's configuration, and keeps
  a small summary of that commit's graph in a cache beside index.json, which
  git ignores. From the cached summaries it writes one file, history.json: the
  first snapshot in full, then one step per commit saying which files were born,
  died, were renamed or changed size, and which file-to-file edges came and
  went, with a full snapshot repeated every 256 steps so that jumping to any
  commit never replays the whole history. The static bundle carries that file
  beside explorer-data.json, and the 3D Local Map fetches it only when you open
  the history control, so a page without history is no slower. At each step the
  picture is fed rather than restarted, exactly as the probe's gentle setting
  did it: renamed files and hubs keep their objects, a born file appears at its
  hub, the hubs are held through the step and released after. A scrubber along
  the bottom carries the steps, a panel beside the picture says what the step
  changed, and the address carries the commit so a link shares a moment. The CLI
  answers the same facts: inspect --at <commit> and inspect --between <a> <b>.
