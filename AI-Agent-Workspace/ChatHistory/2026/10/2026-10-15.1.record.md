## Fork 1: what counts as an entry declaration

An entry is a file that something outside the code starts. Six kinds exist, and each needs its own reading:

1. **A manifest's commands.** In `package.json`, the `scripts` that name a path, and `bin` and `main`. This repository has about twenty such scripts, and the CLI package's `bin` points at a built file that maps back to its source through tsconfig. Other ecosystems declare the same thing differently: a `.csproj` with an executable output type, a web project, Cargo's bin targets, pyproject's scripts, a gemspec's executables. Adapters exist today only for `package.json` and `.csproj`. Cargo, pom, pyproject and go.mod have no Live Docs at all yet.
2. **The language's own main.** C, Go, Rust, Java, C# and Python each have one. No adapter marks any of them today, and in Go and Rust `main` is not even public, so it is absent from the docs.
3. **An opening served.** A route, an address, a procedure, a table. These are already symbols with kinds in the docs since the September openings work.
