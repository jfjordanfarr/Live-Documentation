## Fork 1: what counts as an entry declaration

An entry is a file that something outside the code starts. Six kinds exist, and each needs its own reading:

1. **A manifest's commands.** In `package.json`, the `scripts` that name a path, and `bin` and `main`. This repository has about twenty such scripts, and the CLI package's `bin` points at a built file that maps back to its source through tsconfig. Other ecosystems declare the same thing differently: a `.csproj` with an executable output type, a web project, Cargo's bin targets, pyproject's scripts, a gemspec's executables. Adapters exist today only for `package.json` and `.csproj`. Cargo, pom, pyproject and go.mod have no Live Docs at all yet.
2. **The language's own main.** C, Go, Rust, Java, C# and Python each have one. No adapter marks any of them today, and in Go and Rust `main` is not even public, so it is absent from the docs.
3. **An opening served.** A route, an address, a procedure, a table. These are already symbols with kinds in the docs since the September openings work. ## The four families of edges, and the sidecars

Every file-to-file reference the survey found falls into one of four families, by how the referring file names the referred one.

1. **By path.** HTML's `src`, CSS's `url()`, markdown's link, C's `#include "…"`, Rust's `mod` to a file, PHP's `include`, Ruby's `require_relative`, Kustomize's `resources`, Terraform's `./modules`, Compose's `context`, Godot's `res://`. The referring file alone says where the other file is, up to a search list (`-I` directories, `$LOAD_PATH`, `sys.path`). This is the family the adapters read today; the include rule chosen last night is the search-list half of it.
2. **By name through a convention.** Java's `import a.b.C` reaches `a/b/C.java`; Go's package path reaches a directory; Python's module path walks `sys.path`; PSR-4 maps a namespace to a directory; Rails maps a constant to a file. 4. **By a name resolved at build or run time.** An Xcode asset set, a Helm chart name, an Unreal module, a Swift target, a Unity `Resources` path in a string, a Terraform registry source, `uses: owner/repo@ref`. The manifest or a registry decides what the name means; some are external by nature and stay external dependencies.
