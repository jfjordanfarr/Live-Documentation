  What the library is

  Grilling is thirty lines, and the rest is wrappers. The grill-me skill says
  only "call grilling"; grill-with-docs says "call grilling and
  domain-modeling". The primitive: map the subject as a design tree, where every
  decision branches into the decisions that hang off it. Work it in rounds.
  Each round asks the whole frontier, every question whose prerequisites are
  settled, numbered, each with a recommended answer worded so that "yes" accepts
  it. A question that depends on another still open waits for a later round.
  Facts are the agent's job, found by looking, never asked. Decisions are the
  person's, put to them and waited for. The session ends when the frontier is
  empty, and nothing is built until the person says the understanding is shared.

  "With docs" adds the stress test you asked for, in part. Domain modeling
  challenges each term, invents concrete scenarios "that probe edge cases and

  The SBOM door is open, and the shape you asked about is the wrong one.
  Microsoft's sbom-tool (https://github.com/microsoft/sbom-tool) is
  MIT-licensed, writes SPDX 2.2 by default and SPDX 3.0 on request, and ships as
  self-contained executables for Windows, Linux and macOS, a .NET tool, a NuGet
  package and a Docker image. It finds components with its Component Detection
  libraries over manifests and lockfiles, and it "uses the ClearlyDefined API to
  populate license information", which is a network call. It carries no
  vulnerability data at all. Syft does the same job under Apache 2.0 in either
  format, and vulnerabilities come from a scanner run over an SBOM, Trivy or
  Grype, against a downloaded database (Trivy's SBOM scanning
  (https://trivy.dev/docs/dev/target/sbom/)). So three things follow:

  - Bundling a .NET binary into an npm package or an HTML file means a second
    runtime and tens of megabytes per platform, for a job the person's own CI or
    package manager can do. The right shape is the oracle's: an external tool
    the person has installed, invoked when present.
  - The tendrils' first layer already exists. What a thing's manifests name
    hangs beneath it as strands today. An SBOM adds the transitive components
    from lockfiles and a standard file to read, and vulnerabilities only where
    someone enriched it, which the offline rule says we read and never fetch.
  - Your own first iteration from September 27 is the cheap one: an SPDX or
    CycloneDX file found in a thing's folder is read as a Live Doc in the
    manifests' family, and the strands grow from it. That is ticket T10 in the
    skeleton below, ranked by your "stretch goal". Not too early to plan, too
    early to build.
