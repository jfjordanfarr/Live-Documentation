## The contact-sheet tool

`npm run contact:sheet` draws one build in a fixed list of views and tiles them into one sheet, with a hook that sets a palette before each page loads. I looked at the baseline sheets for tidepool, this repository and the estate. They are whole, and I'm keeping them as the "before" for the palette sheets.

## Two things the sample exposed

- **The 3D key leaves out kinds that sit inside directory bags.** In the Structure link above, green tests and rose assets fill the bags, but the key has no row for either. I'll fix it in the palette round, where the keys are reworked anyway.
- **Assets named from TypeScript are not recorded as connections.** Only an HTML attribute or a CSS `url()` counts today, so the sample's test snapshot image stands unconnected. The sample and its test state this openly. It is a gap in the adapters, not a colour matter, and I have not acted on it.
