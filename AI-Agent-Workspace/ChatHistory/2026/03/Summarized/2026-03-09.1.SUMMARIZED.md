## Turn 7 — User corrects workaround approach, demands root-cause fix

**User**: _"I saw a lot of worrisome laziness indicators/workaround contemplation in the thought traces during that response. I also see that the final aim is to perform a workaround."_ Directs Copilot to: (1) regenerate Live Docs and observe outputs, (2) verify whether HTML artifacts are truly untracked, and (3) check chat archaeology for the vision of HTML Life Documentation. _"Can something break if I delete this file? Is that not what our software answers?"_

**Copilot**: Acknowledges the correction — _"You're right — I was drifting toward a workaround instead of understanding the actual system behavior."_

**Root-cause analysis**: Runs `live-docs:generate` (0 created, 0 updated — template.html not in targets). Performs chat archaeology — finds the Dec 9, 2025 session (Dev Day 35) where the user declared **"total panopticon visibility"**: _"By tomorrow I want the graph to show **all of the CSS, HTML and image assets** the same way we show code."_ The HTML and CSS adapters were built that day, but their globs were only added for `tests/**`, never for `packages/**/src/**` or `scripts/**`.

**Root-cause fix 1 — Glob gap closure**: Adds `*.html`, `*.css`, `*.json` globs to the `packages/**/src/**` and `scripts/**` sections of `liveDocumentationConfig.ts`. Regeneration produces **11 new Live Docs**: 9 CSS files, 1 HTML (`template.html`), 1 JSON (`tsconfig.json`). File count rises from 566 → 577.

**Root-cause fix 2 — HTML adapter enhancement**: The HTML adapter extracts dependencies (external `<script>`, `<link>` URLs) but not public symbols (`id` attributes). But DOM element IDs are the template's public API — client TypeScript consumes them via `getElementById()`. Adds `extractHtmlSymbols()` to the HTML adapter that extracts `id` attributes as public symbols. The template.html Live Doc now produces **66 public symbols** (up from 0), and all 35 client-side anchor references resolve.

Runs `safe:commit` — fails on 3 remaining broken links to deleted `visualize-explorer.ts.mdmd.md` in the product roadmap and scripts architecture doc. Fixes those stale references. Runs again — still fails on more stale `visualize:static` command references. Fixes those too.

Final `safe:commit` — **all green**.
