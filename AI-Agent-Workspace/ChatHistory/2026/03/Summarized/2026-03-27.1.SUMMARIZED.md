## Technical Outcomes

- **Hybrid mixed-content layout (Solution C)**: Files excluded from squarified treemap weights in mixed directories; rendered as card-grid below directory treemap tiles
- **Collapsed-by-default cards**: Click-to-expand with `expandedCards: Set<string>` state; pin-all button for bulk pinning
- **Test-backed golden styling**: `testCoverage` map threaded through render pipeline; CSS `.membrane-card--test-backed` with gold border/glow
- **redrawConnections() API**: Lightweight SVG refresh without FLIP animation — stores anchor references from initial render, re-measures via `getBoundingClientRect()` on slider change
- **Case-insensitive endpoint matching**: `markConnectedEndpoints()` builds lowercase lookup map, applies `.membrane-card__symbol-row--connected` (green) and `--pinned` (blue) CSS classes
- **CSS variable scoping fix**: `--local-column-gap` set on `document.documentElement` instead of `.local-layout`, enabling membrane grid containers to read the variable
- **Fixed-width grid columns**: Inner bands use `repeat(N, 320px)` instead of `1fr` to prevent card width distortion during gap adjustment
- **Dead code removal**: `ClickBehaviorTuning`, `VisualTuning` interfaces removed; template HTML sections removed; `showTypeBadges` hardcoded
