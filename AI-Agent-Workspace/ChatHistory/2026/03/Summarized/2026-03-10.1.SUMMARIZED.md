## Technical Outcomes

**CI Repairs**: Two long-standing CI failures fixed. The Pages workflow referenced the old `live-docs:visualize:static` script name (renamed during Dev Day 75's server retirement). The integration test eagerly loaded a TypeScript oracle module that was deleted during the SCIP migration (Dev Day 69), crashing at module load time. The oracle and all 177 lines of associated dead code were excised entirely rather than wrapped in a lazy loader.

**Benchmark Regeneration**: Two bugs fixed in `regenerate-benchmarks.ts`. The first: C# materialized fixtures' `global.json` files pin older .NET SDK versions, causing `scip-dotnet` to fail when only .NET 10 is installed. Fix: patch `global.json` with `"rollForward": "latestMajor"` before indexing. The second: `toRelativePathFromUri()` used `replace("file:///", "")` which strips the leading `/` on Linux, producing broken relative paths with random temp-directory suffixes. Fix: use Node's `fileURLToPath()` instead. Together these eliminated path churn in expected.json files across regeneration cycles.

**Phantom Edge Elimination**: The `detectInheritance()` function in `graph.ts` read raw source files and applied class-hierarchy regexes that matched inside string literals and template strings, producing phantom `extends`/`implements` edges. The `resolveTypeToLiveDoc()` function used a global symbol index without proximity awareness, resolving `Entry` (exported by 7 Rosetta fixtures) to whichever language appeared first. Both were fixed: `detectInheritance` deleted entirely (~240 lines, 4 helper functions), replaced by threading the type-reference role through `ParsedDependency` so extends/implements edges flow through the parsed metadata path. A new `createProximityAwareComparator()` ensures symbol resolution prefers files closest in the directory tree. Result: 16 phantom edges eliminated, 12 Live Docs corrected, Explorer rebuilt at 577 nodes / 2627 links.
