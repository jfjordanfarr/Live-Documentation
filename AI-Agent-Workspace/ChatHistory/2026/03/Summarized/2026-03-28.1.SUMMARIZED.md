## Turn 5 — User catches false "canvas" claim + reports persistent tiny leaf bug (L1213–L1956)

**User** (L1213): Points out two issues: (1) The "tiny leaf node" bug persists — `fallbackHeuristicTypes.ts` renders as a small card floating atop collapsed membranes, exactly the symptom reported in Fix #5. (2) Demands Chat Archaeology regarding the "canvas" remark: _"Perform Chat Archaeology to see places where 'canvas' and 'accessibility' have been mentioned proximal to each other. I have feelings of being gaslit here, as I recall a somewhat recent instance in which I was assured that this was no canvas."_

**Copilot** (L1215–L1956): One compaction event at L1731.

**Chat Archaeology results**: Searches SUMMARIZED files for "canvas", finds the definitive exchange in Dev Day 78 (2026-03-22.1). The prior agent explicitly reported: _"There is no `<canvas>` element in either the Circuit Board or Local Map."_ The Membrane Map is pure DOM (absolute positioning + CSS `transform: matrix()`). Only the Force Graph uses actual `<canvas>` (WebGL via Three.js). Agent admits: _"You are right to feel gaslit. My pre-summary remark was a false statement."_

**Auto-focus root cause investigation**: The focal panel for `types.ts` had `width: 200px` (min-width fix worked) but `min-height: 9.31934px` — the treemap gave this file a 9px tile because it's one of 518 files in the .mdmd folder. The fundamental problem: the focal panel renders at the treemap tile position even when the selected node's parent directories are collapsed, producing a floating overlay instead of an in-grid card.

**First fix attempt**: Auto-expand the directory path to the selected node on initial load. Added initialization-time logic to derive the parent directory from the selected node's path and auto-expand.

**Second fix attempt**: Moved auto-focus from initialization to the `render()` function itself, so it fires on every render (not just initial load).

**Third fix attempt**: Discovered the `trySelectionOnlyUpdate` fast-path was bypassing the auto-focus logic entirely — the structural key didn't change when the selected node changed (same expanded directories, same pins), so the fast path returned early without running the full render. Added a condition to decline the fast path when auto-focus is needed.

**Critical path derivation fix**: The auto-focus was deriving the parent directory from the node's `.id` (which uses `codeRelativePath`, e.g., `packages/shared/src/inference/fallbackHeuristicTypes.ts`) but the treemap hierarchy is built from `node.docRelativePath` (e.g., `.mdmd/layer-4/packages/shared/src/inference/fallbackHeuristicTypes.ts.mdmd.md`). Fixed by reading `selectedNode.docRelativePath`, stripping the filename, and using that as the parent directory.

**Verification**: Playwright confirms `fallbackHeuristicTypes.ts` now renders as a 225x77px card in the properly expanded `inference` directory, not a 9px floating overlay.

## Technical Outcomes

- **Layered opacity dimming model**: Baseline 0.3 for all symbol rows/pins/connections when pins are active; `--pinned` and `--connected` classes restore to 1.0; hover further dims to 0.2 with `--participating`/`--highlighted` exceptions. Replaces the prior green-inset-border approach.
- **Order-of-operations fix**: `clearHoverDimming()` no longer strips persistent `--connected`/`--pinned` classes on mouseleave — these are baseline indicators that survive hover cycles.
- **Auto-focus via `docRelativePath`**: Directory derivation now uses `selectedNode.docRelativePath` (matching the treemap hierarchy built by `buildHierarchy()`) instead of `codeRelativePath`. Plus fast-path bypass in `trySelectionOnlyUpdate` when auto-focus conditions require a full render.
- **Universal pin-all toggle**: `areAllSymbolsPinned()` helper + `onPinAllSymbols` callback on all cards in both browse-renderer and pin-active-renderer. Toggle semantics: if all pinned → unpin all; else → pin all.
- **`__internals__` full participation**: `data-node-id` and `data-symbol` attributes added to Internals rows; `markConnectedEndpoints` no longer skips `__internals__`; both renderers apply `--pinned` class to Internals rows.
- **Reference badges**: `createReferenceBadges()` renders compact relationship indicators (→, ←, ⊲, ◇) from `publicSymbolsExtended` data on symbol rows in both renderers.
- **Detail panel suppression**: Initial `selectNode()` call uses `{ suppressDetailPanel: true }` to prevent forced panel open on page load.
- **"Open in Membrane Map"**: Button in detail panel footer navigates to the selected node's parent directory in Membrane Map view.
