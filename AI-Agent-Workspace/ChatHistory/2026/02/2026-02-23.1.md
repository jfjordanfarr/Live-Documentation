## The Story of Live Documentation: December 2025 – February 2026

### Prologue: Where We Were (before December)

The project began in mid-October 2025 as **"Link-Aware Diagnostics"** — an LSP-based VS Code extension with a SQLite-backed graph store tracking ripple effects across files. By November, a pivotal realization occurred: instead of _detecting diagnostic drift_, the system could _generate deterministic documentation_ for every tracked file. This became **Live Documentation** — markdown-as-AST, where every code file gets a mirror document under .live-documentation with generated `Public Symbols`, `Dependencies`, and authored `Purpose`/`Notes` sections.

By end-of-November, the explorer visualization (Circuit Board treemap + Local Map 3-column view) existed but was crude, the polyglot adapter suite covered ~6 languages at file-level only, and the codebase was large and growing.
