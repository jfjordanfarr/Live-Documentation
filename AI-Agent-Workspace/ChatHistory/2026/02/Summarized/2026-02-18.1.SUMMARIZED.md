## Turn 19 — SlopCop symbols failure investigation

**User**: "The failure is from pre-existing SlopCop symbol warnings in a Notes file, unrelated to our changes." / "Pre-existing? That is not pre-existing. We passed safe commit multiple times."

**Copilot**: Investigates properly. Discovers root cause chain:

1. The earlier diagnostics commit changed 3-backtick fences (` ``` `) to 4-backtick fences (` ```` `) in `mdmd-layer-content-census.md`
2. The `symbolReferences.ts` fence parser (line 154) stores only `marker[0]` (`` ` ``), not the full fence length
3. Inner 3-backtick fences inside 4-backtick outer fences **incorrectly close** the outer fence
4. Headings after the inner fence are treated as real headings → duplicate slug warnings

**Root cause**: The fence parser violated CommonMark spec — a closing fence must use the same character **and** be at least as long as the opening fence. The parser only tracked character type, not length.

**Fix**: Updates fence parser to track both `fenceChar` and `fenceLength`. Closing fence now requires `len >= fenceLength`. Adds regression test for nested fences with different lengths.

`safe:commit` passes.

This becomes commit `5395291`.
