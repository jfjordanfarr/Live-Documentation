## Turn 9 — User asks about comment stripping vs docstring stripping

**User**: "Does `stripCStyleComments` also handle docstrings, or is that separate?"

**Copilot**: Confirms that `stripCStyleComments` handles both `//` line comments and `/* ... */` block comments (which includes `/** ... */` Javadoc/JSDoc-style docstrings). The function's regex `\/\*[\s\S]*?\*\/` matches all block comment variants including documentation comments. For languages with non-C-style comments (Python `#`, Ruby `#`, PowerShell `#`), each language's `stripComments` function handles its own comment syntax, but the factory provides a unified interface.
