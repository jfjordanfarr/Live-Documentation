- **Copilot**: Discovered fundamental issue: Java's ProcessBuilder on Windows tries to run `"mvn"` literally, but Maven on Windows is `mvn.cmd`. ProcessBuilder doesn't auto-resolve `.cmd` extensions like PowerShell does. This is a known scip-java Windows bug.
