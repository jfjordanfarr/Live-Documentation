## Turn 09
- **User**: Asked about easiest format for consuming multiple knowledge sources:
  > "From an implementation perspective, what would be the easiest format for you to consume numerous different sources of knowledge... for the purposes of integrating into a putative global map of a workspace's interconnectedness?"

- **Copilot**: Proposed `PendingEdge` as canonical intermediate format:
  ```typescript
  interface PendingEdge {
    sourceUri: string;
    targetUri?: string;
    targetSymbol?: string;
    kind: EdgeKind;
    confidence: number;
    provenance: string;  // 'lsif' | 'scip' | 'llm:phi3' | 'adapter:ruby'
  }
  ```
  
  **Three-stage pipeline**:
  1. Collection: Each source emits PendingEdge[] to NDJSON files
  2. Aggregation: Stream-merge, vote across LLM samples
  3. Live Doc Update: Write to `## Dependencies` sections
  
  **Key insight**: No SQLite needed — NDJSON for staging, Live Docs for truth.
