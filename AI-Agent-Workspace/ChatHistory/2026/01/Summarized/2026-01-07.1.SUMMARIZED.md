## Turn 10
- **User**: Reported static site bug — Purpose/Notes sections not rendering (empty), while live server worked correctly.

- **Copilot**: Investigated `parseLiveDocSections()` regex in detailPanel.ts:
  
  **Root cause**: JavaScript regex multiline mode gotcha
  - Lookahead `(?=\n## |$)` failed because in multiline mode, `$` matches end-of-ANY-line
  - After parsing `### Purpose\n`, the `$` matched at the line end, causing lazy `*?` to stop prematurely
  
  **Fix**: Changed lookahead from `(?=\n## |$)` to `(?=\n## \w)`
  - `\n## \w` matches level-2 headers but not level-3+ (because `\w` requires word char, not `#`)
  
  Built static site, tested with Playwright MCP → Authored content now renders correctly.
