## The Canonical Intermediate Format

I'd propose a **PendingEdge** format that all sources emit:

```typescript
interface PendingEdge {
  sourceUri: string;           // workspace-relative path
  sourceSymbol?: string;       // specific symbol, if known
  targetUri?: string;          // resolved target path (null if unknown)
  targetSymbol?: string;       // target symbol name
  kind: EdgeKind;              // 'depends_on' | 'references' | 'implements' | 'calls' | 'uses'
  confidence: number;          // 0.0-1.0
  provenance: string;          // 'lsif' | 'scip' | 'llm:phi3' | 'adapter:ruby' | 'gitlab-kg'
  reason?: string;             // human-readable (especially for LLM explanations)
  location?: { line: number; column: number }; // source location if available
}
```

**Why this works:**

| Requirement | How PendingEdge Handles It |
|-------------|---------------------------|
| LSIF/SCIP | Already produce similar structures; trivial transform |
| LLM | Simple JSON schema; easy to prompt for |
| Polyglot adapters | `DependencyEntry` → `PendingEdge` is 1:1 |
| Unresolved targets | `targetUri: null` with `targetSymbol` only |
| Confidence tiers | Numeric + `provenance` for source tracking |
| Conflict detection | Same (source, target, kind) from multiple provenances |

### Why NDJSON Files (Not In-Memory)

| Concern | NDJSON Solution |
|---------|-----------------|
| **Memory** | Stream one line at a time; never load full set |
| **LLM Sampling** | Each sample writes its own file; merge later |
| **Resumability** | If interrupted, completed batches survive |
| **Auditability** | Raw LLM outputs preserved for debugging |
| **Incremental** | Only regenerate changed sources |

### LLM Multi-Sample Voting

With qwen3-coder:30b (or any local model), the pattern is:

```typescript
// Pseudo-code for LLM edge inference
for (const sourceFile of workspaceFiles) {
  const samples: PendingEdge[][] = [];
  
  // Sample 3-5 times
  for (let i = 0; i < 5; i++) {
    const response = await ollama.chat({
      model: "qwen3-coder:30b",
      messages: [buildEdgeInferencePrompt(sourceFile, workspaceFiles)]
    });
    samples.push(parseEdges(response));
    
    // Write each sample to disk immediately
    await appendNdjson(`llm-batch-${sourceFile.hash}-${i}.ndjson`, samples[i]);
  }
}
```

Aggregation then votes:
```typescript
// For each unique (source, target, kind) tuple:
const votes = samples.filter(s => s.has(edge)).length;
const confidence = votes / samples.length; // e.g., 4/5 = 0.8
```
