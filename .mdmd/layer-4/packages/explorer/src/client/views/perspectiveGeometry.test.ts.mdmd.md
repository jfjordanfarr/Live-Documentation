### Purpose
Checks the correspondence between distinct native symbol curves and a shared file connection, and the order of reversible containment and movement phases.

### Notes
Uses different routes with displaced endpoints to verify exact rest geometry, common aggregate geometry and an intermediate interpolation. Three nested directory levels establish ancestor-first removal and the reverse reveal. Browser journeys separately verify capture of real routes and shells; these pure tests do not judge visual quality.

Since 2026-11-07 the module also reads a wire's outline from its path data, and three cases hold it: the 2D map's forms (M, L, C, Q and polygons) are read and any other (relative commands, arcs, a missing move, an odd number) refused, so that the browser samples it instead; a cubic's flattened length agrees with a fine numerical integration within 0.05 px on three curves, a gentle one, a reversed one and a short one; and samples stand at equal distances, both ends exact, within 0.2 px along a curve.
