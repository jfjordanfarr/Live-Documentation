### Purpose
The scenario table: the still-picture scenarios of the 2D Local Map, written once in tokens and run over every Rosetta program and this repository's own map.

### Notes
Each scenario names the cases of the older browser specs whose still-picture promises it carries (`replaces`), for the ledger of conversions; none of those cases is deleted, since each also holds promises the table does not carry, literals or gestures, and a case is split rather than retired ([the root's rulings on the scenario builder's first handback](../../../../../AI-Agent-Workspace/AgentSessionHistory/2026/11/2026-11-18/2026-11-18.1.record.md#work-notes-the-scenario-builders-first-handback)).
