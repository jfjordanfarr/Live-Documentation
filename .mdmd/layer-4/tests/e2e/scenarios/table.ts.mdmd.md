### Purpose
The scenario table: the still-picture scenarios of the 2D Local Map, written once in tokens and run over every Rosetta program and this repository's own map.

### Notes
Each scenario names the cases of the older browser specs whose still-picture promises it carries (`replaces`), for the ledger of conversions; none of those cases is deleted, since each also holds promises the table does not carry, literals or gestures, and a case is split rather than retired ([the root's rulings on the scenario builder's first handback](../../../../../AI-Agent-Workspace/AgentSessionHistory/2026/11/2026-11-18/2026-11-18.1.record.md#work-notes-the-scenario-builders-first-handback)). The camera's zoom is not in the address, so a scenario farther out carries its presses of Zoom Out.

`knownGaps` lists by name, map by map, the compiler's edges the docs are known to lack at the oracle's file, each with its reason and the date it was listed. It is a baseline, the lowest rank of the frame: a recorded exception, not agreement with the compiler, and the table reports each excuse on a verdict line of rank baseline beside the oracle's. It exists because the C-family adapters record a header's include where the compiler records the use of a definition, which `npm run oracle:compare` reports as 15 missing edges on each of the C and C++ programs; at the processor's header one of them is in reach, `src/processor.h uses src/processor.c` (and its C++ pair). It is frozen here rather than computed from the docs' own comparison with the compiler, which would excuse whatever the docs lose, and an entry that is no longer a gap turns the table red as stale (the root's correction of 2026-11-18). See [the owner's proposal](../../../../../AI-Agent-Workspace/AgentSessionHistory/2026/11/2026-11-17/2026-11-17.1.record.md#turn-8) and [the frame they accepted](../../../../../AI-Agent-Workspace/AgentSessionHistory/2026/11/2026-11-17/2026-11-17.1.record.md#roots-reply-to-turn-11-as-delivered).
