  - **Why.** On Node 22, a generation stopped for 5–11 s while V8 optimized the PowerShell grammar's lexer. Node 22 drains V8's background work whenever its event loop has nothing to wait for, and its main thread waited for that compile. Node 24.0.0 stopped waiting on such work.

  - **What it gave.** Generation of this repository took 12–22 s on Node 26 against 28–46 s on Node 22 (load 8–19).
  - **What it did not change.** The Live Docs, the graph and the oracle comparisons are byte-identical on both. Both report Unicode 17.0, so the history cache's key does not change on that account.
